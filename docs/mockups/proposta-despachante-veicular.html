05 — Diferencial

WhatsApp integrado ao processo ✱

Cada mensagem nasce vinculada a um cliente, processo, cobrança ou tarefa — via API oficial, nunca simulação de WhatsApp Web.

Gatilhos operacionais

  • Processo criado → confirma e envia código de acompanhamento.
  • Documento faltante → solicita com instrução de envio.
  • Pendência criada → informa motivo, responsável e prazo.
  • Processo pronto → avisa disponibilidade e próximos passos.
  • Cliente respondeu → pausa a automação e chama o atendente.

Régua de cobrança

  • Ao gerar → resumo, valor, vencimento e link de pagamento.
  • Antes do vencimento → lembrete configurável.
  • No vencimento → aviso objetivo no dia.
  • Após o vencimento → sequência gradual com limite.
  • Pagamento identificado → interrompe tudo e confirma.
Automação com controle humano: mensagens sensíveis exigem aprovação do administrador, e qualquer régua pode ser pausada por cliente, processo ou cobrança.

07 — Tecnologia

Estrutura técnica

Interface

Aplicação web responsiva / PWA — ícone na tela do celular, rápida em internet comum.

Backend

API com regras de negócio, permissões, automações e integrações.

Banco de dados

PostgreSQL gerenciado — dados estruturados, histórico e relatórios.

Pagamentos

Gateway com Pix, boleto e link — baixa automática por webhook.

Segurança e LGPD

Acesso por perfil, documentos privados, auditoria e política de retenção.

Monitoramento

Logs, alertas, backups automáticos e restauração testada.
